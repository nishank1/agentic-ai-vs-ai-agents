# 01 - LLM

This is the simplest possible starting point.

## Idea

A user sends a prompt directly to an LLM, and the LLM returns a response.

```text
User
  ↓
LLM
  ↓
Response
```

## What this example teaches

- How to load environment variables
- How to initialize an LLM client
- How to send one prompt
- How to print the result

## Run

```bash
python 01_llm/simple_llm.py
```
